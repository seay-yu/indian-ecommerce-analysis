# 🛍️ 印度电商数据分析项目

> 📌 **项目状态**：数据清洗已完成 ✅ | 深度分析已完成 ✅

**项目简介**：基于 Kaggle 公开数据集，对印度电商平台的 25 万条销售记录进行多维度 SQL 分析，涵盖客户分层、产品表现、物流效率三大方向，输出可落地的业务洞察与改善建议。

**数据库**：MySQL 8.0 | 数据库名：`indian_ecommerce_project`

---

## 📁 数据来源

- **数据集名称**：Indian E-Commerce Sales Analytics Dataset
- **作者**：[Jatin Khandelwal](https://www.kaggle.com/jatinkhandelwal112)
- **来源平台**：[Kaggle](https://www.kaggle.com/datasets/jatinkhandelwal112/indian-e-commerce-sales-analytics-dataset)
- **许可协议**：CC0: Public Domain（公有领域）
- **数据规模**：25 万条销售记录 | 4 万名客户 | 2,000 款产品
- **表结构**：
  - `customers`：客户主数据，记录客户个人信息、会员等级（Gold/Platinum/Silver）及历史消费汇总
  - `products`：产品主数据，记录产品品类、品牌、定价及用户评分
  - `sales`：销售订单明细，记录每笔交易的订单信息、支付方式、物流状态及客户评价

📄 完整字段定义：[data_dictionary.md](data_dictionary.md)

**关键外键关系**：
- `sales.Customer_ID` → `customers.Customer_ID`
- `sales.Product_ID` → `products.Product_ID`

## 📊 分析目标

本项目围绕以下三个业务方向展开深度分析：

| 分析方向 | 业务问题 | 核心发现 |
|----------|----------|----------|
| **物流效率分析** | 哪些区域配送时效过长？是否影响客户满意度？ | ✅ 平均时效 4.5 天，各邦差异极小，物流不是业务瓶颈 |
| **客户分层贡献** | 不同 Tier 客户的消费贡献差异有多大？ | ✅ Platinum 贡献 90.08% 销售额，是绝对核心价值来源 |
| **流失风险识别** | 高价值客户是否正在流失？ | ✅ 数据集覆盖期内无实际流失，活跃率接近 100% |

## 🔧 数据清洗（已完成）

在进行分析之前，对原始数据执行了以下清洗操作：

1. **日期字段类型转换**：将 `customers.Date_of_Birth`、`sales.Order_Date`、`sales.Delivery_Date` 从 `VARCHAR` 改为 `DATE` 类型，确保日期计算函数的正确性。
2. **零日期处理**：将原始 CSV 中的占位符 `'0000-00-00'` 统一替换为 `NULL`（表示缺失值）。
3. **严格模式兼容**：在转换过程中临时关闭 MySQL 严格模式，清洗完成后恢复（兼容 MySQL 8.0，已移除废弃参数 `NO_AUTO_CREATE_USER`）。

## 📈 分析成果

### 洞察一：物流体系运行高效，各邦时效高度均衡

| 指标 | 数值 |
|------|------|
| 平均配送时效 | 4.50 天 |
| 最快配送 | 2 天 |
| 最慢配送 | 7 天 |
| 延迟订单（>7天）占比 | **0%** |

- Top 6 订单量最大的邦（UP、Rajasthan、Haryana、Maharashtra、Punjab、Gujarat）时效均在 4.49-4.51 天之间，差异极小
- 配送时效与客户评分无明显关联，快速配送（1-3天）和正常配送（4-7天）的评分均为 4.40 分
- **结论**：当前物流体系运行稳定，各区域覆盖均衡，物流不是业务瓶颈，建议维持现有标准


### 洞察二：Platinum 客户贡献超 90% 销售额，是绝对核心价值来源

| 客户等级 | 客户占比 | 销售额占比 | 客单价 | 人均消费 |
|----------|---------|-----------|--------|----------|
| **Platinum** | 68.37% | **90.08%** | 28,480.68 | 195,337.77 |
| **Gold** | 16.73% | 6.77% | 10,830.85 | 59,988.88 |
| **Silver** | 14.90% | 3.15% | 7,372.33 | 31,373.54 |

- Platinum 客户客单价（28,480）是 Gold（10,831）的 **2.63 倍**，是 Silver（7,372）的 **3.86 倍**
- 客户结构呈“倒金字塔”型：最高等级客户占 68.37%，说明平台客户质量整体较高
- 各等级客户活跃率均在 **98% 以上**，客户粘性强
- 全等级 Top 1 品类均为 **Electronics（电子产品）**，是平台绝对核心品类
- **结论**：Platinum 是核心价值来源，应持续维护其体验，同时通过品类拓展引导 Gold/Silver 客户升级


### 洞察三：数据集覆盖期内客户保持活跃，无实际流失信号

| 客户等级 | 平均 Recency | 活跃率 | 状态 |
|----------|-------------|--------|------|
| Platinum | 818 天 | 100% | 数据集时间范围影响 |
| Gold | 816 天 | 100% | 数据集时间范围影响 |
| Silver | 814 天 | 98.56% | 数据集时间范围影响 |

- 各等级客户平均 Recency 为 **814-818 天**（约 2.2 年），高度一致，说明数据集采集结束时间距今较远
- 数据集最后订单日期集中在 2024 年下半年（距今 650-820 天），这是 Recency 偏高的根本原因
- 在数据集覆盖期内，各等级客户活跃率均接近 100%，无实际流失信号
- 流失客户最后的购买品类以 **Electronics（电子产品）** 为主（5,930 单，3.85 亿），与平台核心品类一致
- **结论**：数据集覆盖期内客户保持活跃，未发现实际流失问题。在实际业务中建议将 Recency 阈值与数据时间范围对标调整


### 📊 业务建议总结

| 方向 | 建议 |
|------|------|
| **物流** | 维持现有标准，无需大规模优化投入 |
| **客户运营** | 聚焦 Platinum 客户体验维护；通过品类拓展引导 Gold/Silver 客户升级 |
| **流失预防** | 实际业务中应重点关注高客单价但低频的 Platinum 客户，避免其长期不活跃 |
